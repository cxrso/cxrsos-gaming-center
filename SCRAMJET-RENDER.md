# CXRSO Browser — Scramjet Engine

This service is isolated in `/scramjet`; it does not replace or modify the Gaming Center's existing games.

## Deploy on Render (free web service)

1. Sign in to Render and choose **New → Blueprint**.
2. Connect the GitHub account that can access `cxrso/cxrsos-gaming-center`.
3. Select this repository and the `main` branch. Render detects `render.yaml`.
4. When prompted, set `ACCESS_PASSWORD` to a strong, unique access code. `SESSION_SECRET` is generated by Render.
5. Create the service using the **Free** plan.

Render will build from `scramjet/` and start the Fastify server. The health check is `/health`.

## Notes

- Based on the official MercuryWorkshop Scramjet-App implementation and its published package versions.
- Scramjet is experimental; no proxy can guarantee every site will work. Some services restrict datacenter IPs, CAPTCHA, sign-in, DRM, or embedded playback.
- Render's free web services sleep after 15 minutes without inbound HTTP requests or WebSocket messages and may take about a minute to wake.
- The service requires an access code. Do not remove the login gate or share the access code publicly.
- The Wisp transport disables UDP and blocks loopback/private network destinations as defense-in-depth. These safeguards are not a substitute for monitoring and abuse controls.
- Scramjet and its upstream dependencies retain their own licenses. See the upstream project and package metadata for license details.
